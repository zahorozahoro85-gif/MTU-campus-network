# MTU Campus Network Project

## Project Overview
Design and implementation of a fictional campus network.

## Team Members
1. Network Administrator
2. Network Engineer
3. Cisco Configuration Engineer
4. Documentation Officer
5. Network Security Administrator

## Project Objectives
- Design a campus network.
- Create physical and logical diagrams.
- Configure network devices using Cisco Packet Tracer.
- Test network connectivity.
- Document troubleshooting procedures.

## Tools
- Kali Linux
- Git and GitHub
- Cisco Packet Tracer
